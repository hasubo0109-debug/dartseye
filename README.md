# DARTS EYE — スマホ用ダーツ自動スコア（PWA）

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作成（例：`darts-eye`、Public）
2. このフォルダの6ファイル（index.html / manifest.json / sw.js / icon-192.png / icon-512.png / apple-touch-icon.png）をアップロード
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 表示されたURL（https://ユーザー名.github.io/darts-eye/）をiPhoneのSafariで開く
5. 共有ボタン →「ホーム画面に追加」

※カメラはHTTPSでないと動きません（GitHub PagesはHTTPSなのでOK）。

## 初回セットアップ
1. スマホをボード横の斜め前に三脚で固定（ボード全体が映る位置）
2. ホーム →「カメラ設定」→ 映像上で 20 → 6 → 3 → 11 のダブル外周の中央を順にタップ
3. 水色の線がリングに重なるよう赤い十字をドラッグで調整 →「保存」
4. 「検出テスト」で何本か投げて判定を確認。ズレる場合は「リング位置の微調整」「検出の設定」を調整

## 更新するとき
index.html を差し替えたら、sw.js 1行目の `VERSION` の数字も上げてください（古いキャッシュが残るのを防ぎます）。

## 判定が苦手なこと（修正バーやタップで直せます）
- 0.5秒より速い連投（1本まとまってしまう）→ 1秒くらい間を空けると安定
- 先に刺さった矢の真後ろに隠れた矢 →「？ 矢を検出できませんでした」バーで OUT／入力
- 盤外のミス・跳ね返り → 同じくバーから OUT
- 矢が矢に刺さった・ぶら下がった → 検知できた場合は「⚠ 矢に当たった可能性」バーで0点にできる
- ゲーム開始時点で刺さったままの矢を抜くと、新しい矢と数えることがある → 開始前に盤面を空に

## 仕様メモ
- ゲーム：COUNT-UP（8R）／01（301〜901・オープン/ダブル/マスターアウト）／CRICKET（ソロ・8/15/20R）
- 演出：BULL、T15〜T20、HAT TRICK・TON 80・THREE IN THE BLACK・THREE IN A BED・HIGH/LOW TON・WHITE HORSE・5〜9 MARKS・GAME SHOT
- 記録・設定はスマホ内（localStorage）に保存。サーバー送信なし
- 判定：背景差分で新しく刺さった矢を見つけ、カメラ位置側の端を矢先として盤面座標に変換
